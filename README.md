# Skill-Lab 🧪

Kuratierte Skills für AI-Agenten — entstanden aus einer **wöchentlichen Recherche** auf X & Reddit nach realen Problemen, die Nutzer mit AI-Agenten (und AI allgemein) haben.

## So funktioniert's

Jede Woche:
1. **Recherche** — X + Reddit nach Leidenspunkten mit AI-Agenten/AI durchsuchen
2. **Bewerten** — Häufigkeit, Schmerz, Machbarkeit, Einzigartigkeit
3. **Top 5 filtern** — die vielversprechendsten Potenziale
4. **Auswahl** — ein Problem wird ausgewählt, dafür ein Skill entwickelt
5. **Veröffentlichen** — der fertige Skill landet hier in `/skills/`

> Duplikat-Schutz: Eine laufende Liste wird in einem Google-Sheet gepflegt, damit kein Skill doppelt entsteht.

## Struktur

```
skill-lab/
├── README.md
├── skills/          ← die veröffentlichten Skills (je ein Ordner pro Skill)
│   └── <skill-name>/SKILL.md
└── wochen/          ← Verlauf der wöchentlichen Recherchen & Entscheidungen
```
